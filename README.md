# Simple Expense Tracker

This is a basic console-based project built using **pure Python** in Google Colab. It runs an interactive loop that lets you track daily spending, view history, and calculate total expenses.

## How it works
1. **Option 1 (Add expenses):** Input the item name (like 'gym fees' or 'books') and the amount, and it saves it into a list.
2. **Option 2 (View expenses):** Displays all your added entries side-by-side with their prices.
3. **Option 3 (Total expenses):** Automatically runs through your list and shows the final total sum of your spending.
4. **Option 4 (Exit):** Ends the program loop safely.

##  Concepts Used
- **While Loops:** To keep the menu running continuously until the user chooses to exit.
- **Lists within Lists:** Used to store both the item name and price together as a single record.
- **If-Elif-Else Conditions:** To handle user menu choices (1-4) and handle wrong inputs.
- **Type Casting:** Converting input text to floats so the math calculations work perfectly.
